# CLIENTES

Uma pasta por cliente, com o nome oficial em MAIÚSCULAS (razão social ou nome do MEI), sem data no nome.

```
CLIENTES/
  NOME OFICIAL DO CLIENTE/
    DOCUMENTOS ADMINISTRATIVOS/   <- cartão CNPJ, contrato social, CCMEI, procurações, contrato de honorários
    2026/
      2026-09/                    <- competência = mês de FECHAMENTO (AAAA-MM)
```

## Nome dos arquivos

- Competência: `AAAA-MM - TIPO - descrição` (ex.: `2026-09 - DAS - PGDAS-D.pdf`)
- Administrativos: `TIPO - descrição - AAAA` (ex.: `ALTERAÇÃO CONTRATUAL - 2025.pdf`)

## Duplicados

Nunca apagar direto: mover para `_DUPLICADOS_CONFERIR` e conferir.

Copie `_MODELO CLIENTE` ao cadastrar um cliente novo.
