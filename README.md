# Mauriceia Lima - Assessoria Contábil e Empresarial

Repositório do escritório: modelos, procedimentos, rotinas e estudos.

## Estrutura

| Pasta | Para que serve |
|---|---|
| `ESCRITORIO/MODELOS` | Contratos padrão, propostas de honorários, cartas a clientes |
| `ESCRITORIO/PROCEDIMENTOS` | Passo a passo das rotinas (checklist mensal, abertura de empresa etc.) |
| `LEGISLACAO` | Resumos de leis e mudanças importantes (ex.: Reforma Tributária) |
| `CLIENTES` | Apenas a **estrutura** das pastas por cliente (ver regra abaixo) |
| `ESTUDOS` | Anotações de cursos e atualizações |

## Regra de ouro (LGPD)

- **Documentos de clientes NÃO sobem para o GitHub** (notas, guias, extratos, folha, CPF).
  Eles ficam no computador/Drive, seguindo a mesma estrutura de `CLIENTES`.
  O arquivo `.gitignore` já bloqueia isso automaticamente.
- **Certificados digitais** (.pfx, .p12) e chaves nunca entram aqui.
- Mantenha este repositório **privado**.
